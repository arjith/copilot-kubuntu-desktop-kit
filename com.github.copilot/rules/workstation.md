# Workstation boundaries

Read the project's instructions and Git status before changing a repository.
Preserve existing user work and use its runtime, dependency and test conventions.

For desktop/system work, inspect the current machine and keep changes scoped.
Do not reboot, log out, repartition, broadly kill processes, provision unrelated
services or relax security without explicit authorization.

Keep sign-in and permission approval with the user. Never export their personal
Copilot configuration, credentials, session history, private logs or screenshots
as repository templates.

Use relevant checks to verify the requested outcome. A running process or
successful input dispatch does not prove the visible task worked.
Keep delegation bounded and models inherited unless the user chooses otherwise.
